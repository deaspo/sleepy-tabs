# Sleepy Tabs Guardian Support

We want teams to feel confident deploying Sleepy Tabs Guardian. Use the resources below to troubleshoot issues, request features, or get in touch with the maintainers.

## Contact

- Email: [support@sleepytabs.app](mailto:support@sleepytabs.app)
- GitHub: [Open an issue](https://github.com/deaspo/sleepy-tabs/issues) with detailed reproduction steps and logs when available.

## Self-Service Resources

- [Chrome Web Store listing](https://chromewebstore.google.com/detail/bfgeeiahcekoeafnbjdacfdgbhehgneb) for installing or sharing the latest published build.
- [Getting Started Guide](getting-started.md) for installation prerequisites.
- [Usage Guide](usage.md) to understand automation modes and memory thresholds.
- [Privacy Policy](policies/privacy-policy.md) and [Terms of Use](policies/terms-of-use.md) for compliance questions.

## Troubleshooting Checklist

1. Confirm you are running the latest build of the extension (see the Options page footer for version info).
2. Re-run `npm run build -w extension` if you sideloaded the unpacked version and recently pulled new changes.
3. If the native companion is installed, make sure the background service indicates **Connected** in the dashboard.
4. Capture console logs (`chrome://extensions`, enable developer mode, inspect views) when reporting issues.

## Feature Requests

Have an idea to make Sleepy Tabs Guardian better? Submit a GitHub issue tagged `enhancement` with context about the workflow you want to improve. We prioritize items that protect performance, reduce manual tab triage, or simplify deployments.

## Security or Privacy Concerns

Report sensitive issues privately to [support@sleepytabs.app](mailto:support@sleepytabs.app). Include a secure contact method so we can follow up promptly.
