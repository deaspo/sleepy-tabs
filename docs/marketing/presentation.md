# Sleepy Tabs Guardian Pitch Deck

---

## Slide 1: Problem

- Knowledge workers juggle 30+ tabs daily
- Idle tabs drain memory, battery, and focus
- Existing tab managers lack visibility and fine control

---

## Slide 2: Solution

- Auto-sleep inactive tabs with user-approved countdowns
- Reload memory-heavy pages before they freeze workflows
- Surface actionable telemetry in a live dashboard

---

## Slide 3: How It Works

- Manifest V3 extension orchestrating Chrome APIs
- Playwright companion connects to Chrome DevTools Protocol for metrics + lifecycle
- IndexedDB stores on-device logs, side panel visualizes health

---

## Slide 4: Key Differentiators

- Consent-first onboarding with per-tab toggles
- Real resource data, not guesses
- Works across all tabs automatically; no manual tagging needed
- Built with modern TypeScript, Vite, React

---

## Slide 5: Target Users

- Remote teams living in the browser
- Developers running debug-heavy sessions
- Power users with research or support workflows
