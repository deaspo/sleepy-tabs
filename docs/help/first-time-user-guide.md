# Sleepy Tabs Guardian — First-Time User Guide

This walkthrough explains how to install, open, and configure Sleepy Tabs Guardian right after you grab it from the Chrome Web Store. Follow it step by step; no previous experience is required.

## 1. Install the Extension

1. Open Google Chrome (or any Chromium browser such as Microsoft Edge).
2. Visit the official listing: https://chromewebstore.google.com/detail/bfgeeiahcekoeafnbjdacfdgbhehgneb
3. Click **Add to Chrome** (Edge shows **Get**).
4. When the confirmation window appears, choose **Add extension**.
5. Wait for the success pop up. Chrome may open a new tab with a welcome or consent screen—keep it open for the next section.

> **Tip:** Pin the Sleepy Tabs icon so it stays visible. Click the puzzle piece icon in the toolbar → find **Sleepy Tabs Guardian** → click the pin symbol.

## 2. Complete the Consent Page

The first tab that opens after installation is the Consent page. It makes sure you understand what the extension does before it starts managing your tabs.

1. Read the short explanation on the page.
2. Click **I Agree** (or the equivalent confirm button). This unlocks the rest of the features.
3. The page will show a success message and point you back to the toolbar popup.

If you close the consent tab by mistake, open the popup (see the next section) and choose **Open consent screen**.

## 3. Open the Popup

1. Click the Sleepy Tabs cloud icon in the toolbar.
2. The popup shows the status of your current tab and quick actions.
3. Press **Open settings** at the bottom when you are ready to configure timeouts or automations.

> **Need the icon?** If you do not see it, click the puzzle piece icon, then the pin next to **Sleepy Tabs Guardian**.

## 4. Adjust the Main Settings

When you click **Open settings**, a dedicated Options page opens in a new tab. Work through the sections from top to bottom.

1. **Inactivity timeout** – choose how long (in minutes) a tab can sit untouched before Sleepy Tabs puts it to sleep. The default is 5 minutes. Use the slider or type a number.
2. **Memory threshold** – this decides when high-memory pages should be nudged. The default 100 MB works for most users; only raise it if you see too many reminders.
3. **High-memory actions** – pick what should happen when a tab crosses the threshold:
   - For the tab you are currently viewing (Active tab).
   - For tabs in the background (Inactive tabs).
   Set each dropdown to **Show reminder first** if you want a gentle warning, or **Auto sleep** for hands-off cleanup.
4. **Reminder countdown** – controls how long the reminder dialog waits before carrying out the action automatically. Keep 15 seconds if you need time to react.
5. **Automation toggles** – use the switches to turn the features on or off in a single click. Leave them on while you learn the extension.
6. Click **Save** if a button appears. Many controls save immediately; a confirmation toast will appear in the bottom corner.

You can reopen this page anytime via the popup → **Open settings**.

## 5. Use the Dashboard (Side Panel)

The dashboard shows which tabs were slept, which ones used lots of memory, and when it happened.

1. Click **Open dashboard** inside the popup, or use Chrome’s side panel button and select **Sleepy Tabs Guardian**.
2. Tabs are color-coded: green for normal, yellow for reminders, and red for critical events.
3. Click a listed tab to jump back to it quickly.

## 6. Everyday Tips

- **Ignore a tab:** Open the popup and toggle **Ignore this tab** if you never want Sleepy Tabs to touch that site (for example, music streaming).
- **Wake a slept tab:** Click the tab in Chrome; the browser reloads it automatically.
- **See memory info:** The popup shows the last known memory usage and when it was measured.
- **Restore defaults:** If you feel lost, scroll to the bottom of the Options page and press **Restore defaults**. Everything snaps back to the original settings.

## 7. Troubleshooting Checklist

- **Reminders never appear:** Click the puzzle icon → **Sleepy Tabs Guardian** → make sure **Allow this extension to read and change site data** is set to **On all sites**. Some built-in Chrome pages (like `chrome://settings`) do not support reminders at all; this is normal.
- **Tabs stop sleeping:** Confirm the automation toggles are still on in the Options page. Reopen the popup and press **Reload extension** if available, or go to `chrome://extensions`, find Sleepy Tabs Guardian, and click **Reload**.
- **Memory numbers look stuck:** Close and reopen the tab, then try again. If the optional companion app is running, ensure the window shows "connected"; otherwise the extension falls back to approximate numbers.
- **Still confused?** Email support at the address listed in the Chrome Web Store page or open the dashboard and use the **Help** link in the footer.

## 8. Optional Companion App (Advanced)

Sleepy Tabs Guardian works fine without any extras. For the richest memory readings, you can later install the companion app shown in the README. Beginners can skip this entirely until they feel comfortable.
